🔗 노드 연결 (가장 중요!)
• 노드에 마우스를 올리면 상/하/좌/우에 파란 원(앵커)이 나타납니다
• 앵커를 마우스로 꾹 누른 채 드래그 → 연결할 노드 위에서 손을 떼면 연결 완성
• 도착 노드의 어느 부분에 떨어뜨려도 가장 가까운 앵커로 자동 연결됩니다
• 드래그 중 연결할 노드 위에 올라가면 하이라이트되고 선이 앵커에 미리 스냅됩니다
• 연결 중 Esc 또는 빈 곳 클릭으로 취소

• 이미 연결된 선도 끝점(화살표) 핸들 드래그로 다른 앵커에 재연결할 수 있습니다

🖱️ 기타 마우스 조작
• 노드 드래그: 노드 이동
• 노드 이동 시 가까운 도형의 상/중/하·좌/중/우 라인에 자동 정렬 스냅
• 정렬 스냅을 잠시 끄려면 Alt를 누른 채 드래그
• 바탕 드래그: 캔버스 화면 이동 (Pan)
• 모서리 핸들 드래그: 노드 크기 조절
• 선 선택 후 주황 핸들 드래그: 선 곡률 조절

🔲 다중 선택
• 바탕 드래그: 영역 지정으로 다수 선택
• Shift + 클릭: 여러 노드 개별 추가 선택/해제

⌨️ 단축키
• Ctrl + Z: 실행 취소 (Undo)
• Ctrl + Y (또는 Ctrl+Shift+Z): 다시 실행 (Redo)
• Ctrl + A: 전체 선택
• Ctrl + C: 선택 항목 복사
• Ctrl + V: 복사 항목 붙여넣기
• Delete / Backspace: 선택 삭제
• Esc: 선택 취소 / 연결 취소
