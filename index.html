❓ 도움말 & 사용 가이드
🏗️ 시각화 아키텍처 설계
• Flowchart (FC) 범용 업무 흐름 및 게임 이벤트 시퀀스 설계용
• State Machine (FSM) 상태 기반 전환 및 오브젝트 라이프사이클 설계용
• Behavior Tree (BT) AI 의사결정 로직 및 복합적 행동 제어용
• Sequence (SC) 객체간 메시지 교환 및 시간 순 인터랙션 설계용
🛠️ 에셋 편집 및 조작
• 에셋 생성: 우측 팔레트에서 드래그하여 캔버스에 배치하거나 항목을 즉시 클릭하세요.
• 정밀 정렬: 노드 드래그 시 인접 노드와 정렬 가이드가 자동으로 표시됩니다. (임시 해제: Alt)
• 고속 편집: 노드를 더블클릭하거나 F2를 눌러 즉시 레이블을 수정할 수 있습니다.
• 속성 정의: 좌측 인스펙터 패널에서 노드의 변수군, 색상, 크기를 상세히 제어합니다.
▶️ 지능형 로직 엔진 및 검증
엣지(선) 조건식 문법
HP < 30 // 숫자 기반 조건부 분기
Target == "Enemy" // 문자열 동등 비교
isDead // Boolean 변수 존재 여부 체크
Success / Failure // BT 노드 리턴값 매칭
로직 트레이스 (F10)
시작 지점을 정하고 변수값을 입력하여 흐름을 단계별로 시뮬레이션합니다.
정적 검증 (F8)
도달 불가능한 노드, 순환 루프, 고립된 포인트 등 아키텍처 결함을 자동 탐색합니다.
💡 Pro Tip: 생산성 극대화
  • 연결 재구성: 선의 끝점 핸들을 드래그하여 다른 노드나 앵커로 즉시 옮길 수 있습니다.
  • 캔버스 고속 이동: 마우스 우클릭 또는 휠 클릭으로 드래그하면 화면을 자유롭게 유영(Pan)합니다.
  • 전체 보기: F 키를 눌러 모든 노드가 한 화면에 들어오도록 뷰를 자동 피팅하세요.
  • 데이터 영속성: 모든 작업은 시트별로 분리 저장되며, 상단 [내보내기]를 통해 JSON으로 백업 가능합니다.
