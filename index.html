📚 Game Flow Canvas: 궁극의 사용 가이드

🌟 환영합니다!

Game Flow Canvas는 게임 기획자, 개발자, 디자이너를 위한 올인원 로직 시각화 도구입니다. 이 가이드는 도구의 모든 기능을 아주 세세하게 다룹니다. 한 번만 정독하시면 전문가처럼 프로젝트를 설계하실 수 있습니다.

1. 네비게이션 및 인터페이스 (기초)

• 캔버스 탐색: 빈 공간을 클릭 후 드래그하면 화면 전체가 이동(Panning)합니다. 복잡한 차트에서 특정 위치를 빠르게 찾을 때 사용하세요.

• 정밀 줌(Zoom): 마우스 휠을 통해 10% 단위로 확대/축소됩니다. 왼쪽 하단 ⌂ 버튼은 100% 배율로, ⊞ 버튼은 모든 노드가 한눈에 들어오게 맞춥니다.

• 인스펙터 (오른쪽 패널): 선택한 노드의 '데이터'를 직접 수정하는 곳입니다. ID(시스템 식별자)와 레이블(출력 텍스트) 외에도, + 속성 추가 버튼으로 '공격력', '조건식' 등 실제 게임 데이터 필드를 무한히 추가할 수 있습니다.

2. 노드 배치 및 지능형 연결 (핵심)

• 자동 정렬 시스템: 노드를 이동할 때 다른 노드의 중심선이나 경계선에 맞춰 분홍색 가이드 라인이 나타납니다. 픽셀 단위의 완벽한 정렬을 돕습니다. 자유로운 배치가 필요할 때는 Alt 키를 누르세요.

• 스마트 앵커 연결: 노드에 마우스를 올리면 나타나는 4개의 파란 점(앵커)을 드래그하여 연결하세요. 선이 연결된 후에도 노드를 움직이면 선의 경로가 실시간으로 최단 거리로 재계산됩니다.

• 선 경로 커스텀: 연결선을 클릭하면 중앙에 주황색 핸들이 생깁니다. 이를 통해 경로를 수동으로 꺾거나 곡률을 조절할 수 있습니다. 이미 연결된 화살표 끝점을 잡고 다른 노드로 옮겨 붙이는 것도 가능합니다.

🔍 차트 모드별 상세 노드 가이드

🟦 플로우차트 (Logic Flow)

용도: 함수 알고리즘, 퀘스트 진행 순서, 유저 인터렉션 시나리오.

  • 터미널: 알고리즘의 진입점과 탈출구입니다. 반드시 하나 이상의 시작점이 필요합니다.
  • 프로세스: '아이템 획득', '데미지 계산' 등 단일 동작을 의미합니다.
  • 조건(Decision): Yes/No 분기를 만듭니다. 나가는 선을 2개 뽑아 각각 선택지를 부여하세요.
  • 서브루틴: 다른 곳에 정의된 복잡한 로직을 호출할 때 사용합니다 (예: 전투 시스템 호출).

🟩 FSM (State Machine)

용도: 캐릭터 애니메이션 상태, 게임 모드 전환 (로비→인게임), 메뉴 시스템.

  • Initial (초기): 객체가 생성될 때 가장 먼저 점유하는 상태입니다.
  • State (상태): '대기', '공격', '사망' 등 지속되는 물리적/논리적 상태입니다.
  • 전이 (Transition): 연결선 자체가 이벤트입니다. 선 위에 '마우스 클릭 시' 같은 텍스트를 적으세요.
  • 포크/조인: 병렬 상태(동시에 두 상태를 가짐)를 시작하거나 다시 하나로 합칠 때 사용합니다.

🟨 비헤이비어 트리 (AI Tree)

용도: 몬스터 AI, NPC 대화 지능, 자동화된 시스템 스케줄링.

  • 시퀀스(→): 모든 자식 노드가 성공할 때까지 왼쪽에서 오른쪽으로 실행합니다.
  • 셀렉터(?): 자식 노드 중 하나라도 성공하면 즉시 중단하고 상위로 성공을 보고합니다.
  • 데코레이터: '반복하기', '성공할 때까지 시도' 등 하위 노드에 필터를 겁니다.
  • 리프(Leaf/Action): 실제 AI가 수행할 최하단 행동(이동, 소리내기 등)입니다.

🟥 시퀀스 차트 (Interaction)

용도: 서버-클라이언트 통신 패킷 흐름, 클래스 간 메시지 호출 순서.

  • 라이프라인: 차트 최상단에 놓인 객체(유저, 웹서버 등)의 생명 주기입니다.
  • 활성화(Activation): 세로로 긴 사각형은 해당 객체가 '처리 중'임을 나타냅니다.
  • 메시지(화살표): 객체 간 주고받는 요청과 응답을 선의 방향으로 표시합니다.

🚀 프로의 캔버스 팁

• 빠른 복제: 노드를 선택하고 Ctrl + C 한 뒤 Ctrl + V를 연타하면 마우스 위치에 계단식으로 복제됩니다.

• 멀티 시트 활용: 하단 + 버튼을 눌러 시트를 나누세요. 1번 시트에는 '전체 흐름'을, 2번 시트에는 특정 구간의 '상세 로직'을 그려 관리하면 규모가 큰 게임도 문제없습니다.

• 검증 시스템(⚠): 상단의 경고 아이콘을 누르면 '연결되지 않은 노드'나 '고립된 상태' 등을 AI가 분석하여 오류를 찾아줍니다.
